Project Name:FitLog Fitness Website
Short Description:
  FitLog is a modern fitness website that helps users explore   workouts, view detailed exercise information, and manage their  daily workout plans. It provides a simple, responsive, and   user-friendly experience for organizing and tracking fitness  activities.

Technologies Used:
1.React
2.Next.js
3.Tailwind CSS
4.React Icons

5 Key Features
1.Add Exercises to My Plan
      Users can add their favorite exercises or fitness activities to their personal workout plan.
2.View Exercise Details
      Users can click on any exercise to view its detailed information, including duration, equipment, muscle groups, and other relevant data.
3.My Plan Dashboard
      A beautiful and organized dashboard allows users to view and track all their selected exercises in one place.
4.Remove Exercises
      Users can easily remove completed or unnecessary exercises from their workout plan.
5.Workout Statistics
      Users can view useful statistics about their fitness activities, such as total exercises, workout duration, calories burned, and other relevant information.
